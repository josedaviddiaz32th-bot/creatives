## Hook patterns noted for the scriptwriter (TOF)
- Callout of a private habit as a question ("why am I the only one who…").
- Visual paradox in frame one (split face / filter vs real).
- Counterintuitive cause ("worst in the morning" → "pressed in overnight").
- Category gap from the Meta scan: almost nobody leads with the cause; the top category hooks are
  outcome ("I wake up looking like I slept 12 hours") and regret (med-spa). Ours is cause-first.

## Resulting plan
- **Type:** POV group-photo moment → peer talking-head explanation, with code split-screen cutaways.
- **Hook pattern:** identification question about the filter; frame one = moving POV still.
- **Pacing:** single presenter, ~3–4 visual changes per 10s (talking head ↔ stills), captions on.
- **Shot style:** phone-front-camera selfie at night in her bedroom (lamp light), real-looking,
  unretouched; stills for the photo, sleeping, patches-on, morning.
- **Who speaks:** only her (native Kling voice). Friends never speak. Silent with patches on.
- **Product timing:** Face Set visible on the nightstand from her first shot, spoken about only in
  the last ~20–25%; brand name on screen in code and in the caption.
- **Length:** 30–50s (`video.seconds_by_stage.tof`); target ≈ 44s.
- **Format count:** POV/cause-reveal talking head is used once this week (this slot).
